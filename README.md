# Shalom Kambarami - Profile

## Project Description

A semantic HTML5 profile and mini-portfolio page created for the Web Technologies (CIS2103) practical assignment.

## About the Project

This project is a one-page personal profile and mini-portfolio website. It introduces me, shows my technical skills, and provides a Contact Me form.

The page was developed using semantic HTML5 elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

The page also includes a contact form with HTML5 validation.

The Contact Me form contains:

- Full Name
- Email
- Phone Number
- Message

HTML5 validation is used to make sure that the required information is entered correctly. No JavaScript is used for form validation.

## Accessibility Improvements

The page includes the following accessibility improvements:

- Form inputs have associated labels.
- Email uses the appropriate `type="email"`.
- Phone number uses the `type="tel"` input type.
- Required fields use the `required` attribute.
- Input validation uses native HTML5 validation.
- Keyboard focus indicators are provided.
- Text and background colours were selected for readability.
- Navigation links clearly identify the different sections of the page.
